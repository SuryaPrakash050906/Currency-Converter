# Currency-Converter
A Java-based currency converter application that converts one currency into another using predefined exchange rates through a user-friendly console interface.



Currency Converter is a Java application that converts currencies based on predefined exchange rates. The project demonstrates Java programming concepts including user input handling, arithmetic operations, conditional logic, and menu-driven applications.

Features:
• Multiple currency conversions
• Simple and interactive console interface
• Accurate conversion calculations
• Menu-driven operation
• Easy to extend with additional currencies

Technologies Used:
• Java
• OOP Concepts
• Console-Based Interface
